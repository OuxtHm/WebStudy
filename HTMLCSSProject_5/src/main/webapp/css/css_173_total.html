overflow: scroll
가장 눈에 띄는 계약은 전체 9순위로 지명된 서울고 투수 이호범이다. 삼성은 이호범과 계약금 2억5000만원, 연봉 3000만원에 합의했다. 이호범은 신장 190cm, 체중 95kg의 뛰어난 체격조건을 바탕으로 최고 150km/h의 빠른 패스트볼과 완 성도 높은 변화구를 보유했다. 탈삼진 능력이 우수한 정통파 우완으로 평가받는다.
